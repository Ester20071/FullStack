O nome do banco (concessionaria)
É só um nome, não está ligado a nada em nenhum outro arquivo. Você pode mudar só ali e pronto. O MongoDB cria o banco automaticamente com o nome que você colocar.

Resumo visual de interligação
Quer mudar/adicionar um CAMPO:
  models/Carro.js         → define o campo
  routes/carros.js        → cadastrar e atualizar (2 lugares)
  views/carros-gerencia   → formulário + tabela (2 lugares)
  views/carro-editar      → formulário de edição

Quer mudar o TEMA inteiro:
  models/Carro.js         → campos novos
  routes/carros.js        → importação + campos + nomes
  server.js               → nome da rota
  views/*.ejs             → campos + links
A regra de ouro é: o name do input no .ejs tem que ser igual ao campo no model e no routes. 
Se um estiver diferente do outro, não salva no banco

🔎 Lugares que as pessoas ESQUECEM e dão erro
Esses são os erros mais comuns:
1 — Esquecer de trocar o res.render no routes
js// Se renomeou o arquivo mas esqueceu isso, dá erro de página não encontrada
res.render('carros-gerencia') // ← ERRADO depois de renomear
res.render('animais-gerencia') // ← CERTO
2 — Esquecer de trocar a variável passada para o EJS
js// routes/animais.js
const animais = await Animal.find();
res.render('animais-lista', { animais }); // ← tem que bater com o nome no .ejs
html<!-- animais-lista.ejs -->
<% animais.forEach(animal => { %> <!-- ← tem que ser 'animais', igual ao routes -->
3 — Esquecer de trocar o require no routes
js// Se esqueceu isso, o sistema continua buscando os dados de carros
const Animal = require('../models/Animal'); // ← tem que apontar pro arquivo certo
4 — Esquecer de trocar o app.use no server.js
js// Se deixar /carros aqui, os links /animais não vão funcionar
app.use('/animais', animaisRouter); // ← tem que bater com os links das páginas

🎯 Regra de ouro para não errar
Tem 3 coisas que precisam ser iguais sempre:
name do input no .ejs
    ↕ tem que ser igual
campo no model
    ↕ tem que ser igual
campo no req.body do routes
E tem 2 coisas que precisam bater:
{ animais } passado no res.render do routes
    ↕ tem que ser igual
animais.forEach no .ejs

Regra simples para lembrar
Sempre que ver uma dessas 4 coisas, pergunta: "ainda tem o nome do tema antigo aqui?"
1. const { campos } = req.body        → campos = os do model
2. const novoXxx = new Xxx({ })       → Xxx = nome do model
3. res.redirect('/rota/...')          → rota = a do server.js
4. res.render('pagina-...')           → pagina = o arquivo .ejs
